
# Cats vs Dogs Image Classification

## Internship
ShadowFox - AI/ML Engineer Internship

## Project Overview
This project uses a Convolutional Neural Network (CNN)
to classify images into two categories: Cats and Dogs.

## Technologies Used
- Python
- TensorFlow and Keras
- NumPy
- Pandas
- Matplotlib
- Google Colab

## Dataset
Cats vs Dogs image dataset.

Image size: 150 x 150 pixels
Classes: Cat and Dog

## Model Architecture
- Convolutional Neural Network (CNN)
- Data Augmentation
- Dropout Regularization

## Model Performance
Validation accuracy: 71.2%

Experimental threshold: 0.55
Accuracy at selected threshold: 72.8%

## Project Activities
1. Dataset preparation
2. Image preprocessing
3. CNN model development
4. Data augmentation
5. Model evaluation
6. Error analysis
7. Threshold tuning
8. Testing with new images

## Project Structure
- model/: Trained model
- reports/: Evaluation and prediction reports
- notebooks/: Colab notebooks
- sample_images/: Sample test images

## Conclusion
A CNN-based image classifier was developed
to distinguish between cats and dogs.
The model was evaluated using validation data
and tested with new images.
