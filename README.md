# ShadowFox AI/ML Engineer Internship

## About the Internship

This repository contains the projects completed as part of my one-month **AI/ML Engineer Internship at ShadowFox**.

During this internship, I worked on three projects covering beginner, intermediate, and advanced levels. These projects helped me gain practical experience in Python programming, machine learning, deep learning, natural language processing, model evaluation, and application development.

## Projects

### 1. Beginner Level – Cats vs Dogs Image Classification

**Objective:** Build a deep learning model that classifies images into two categories: Cats and Dogs.

**Technologies Used:**
- Python
- TensorFlow and Keras
- Convolutional Neural Networks (CNN)
- NumPy
- Matplotlib

**Work Completed:**
- Dataset preparation and preprocessing
- Image augmentation
- CNN model development and training
- Model evaluation and error analysis
- Prediction threshold comparison

**Results:**
- Improved model validation accuracy: 71.2%
- Best threshold validation accuracy: 72.8%
- Dog precision: 0.705
- Dog recall: 0.784
- Dog F1-score: 0.7424

### 2. Intermediate Level – Car Selling Price Prediction

**Objective:** Develop a machine learning model to predict the selling price of used cars based on different features.

**Technologies Used:**
- Python
- Pandas
- NumPy
- Matplotlib
- Scikit-learn
- Gradio

**Work Completed:**
- Data cleaning and preprocessing
- Exploratory data analysis
- Categorical feature encoding
- Model training and comparison
- Feature importance analysis
- Car price prediction application

**Best Model:** Linear Regression

**Model Evaluation:**
- MAE: 1.4729
- MSE: 6.3708
- RMSE: 2.5240
- R² Score: 0.7528

### 3. Advanced Level – DistilBERT Sentiment Analysis

**Objective:** Implement a pretrained language model to identify whether a given sentence expresses positive or negative sentiment.

**Model Used:** DistilBERT – `distilbert/distilbert-base-uncased-finetuned-sst-2-english`

**Technologies Used:**
- Python
- PyTorch
- Hugging Face Transformers
- Gradio
- Pandas

**Work Completed:**
- Pretrained language model implementation
- Tokenization and attention mask demonstration
- Sentiment prediction
- Model configuration analysis
- Performance evaluation
- Ethical considerations and limitations
- Gradio application development

**Evaluation Results:**
- Accuracy: 100%
- Precision: 1.00
- Recall: 1.00
- F1-score: 1.00

*Note: These results were obtained using a small set of 10 manually labelled test sentences. They should not be considered a measure of general model performance.*
